# Dart / Flutter

- Use the Flutter/Dart SDK constraints in `pubspec.yaml`; run `dart format` and `flutter analyze`.
- Follow the state-management approach already in use (Bloc, Provider, Riverpod, ...); don't add another.
- Keep widgets small; move logic out of `build`.
- Tests: `flutter test`; widget tests for UI changes.
